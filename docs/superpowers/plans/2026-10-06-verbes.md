# Page Verbes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une page `verbes.html` de fiches à retourner pour les 30 verbes de `resource/verbes/verbes_1.pdf` (dessin + français devant ; groupe, formes ます / dictionnaire / て avec furigana derrière), reliée à l'accueil.

**Architecture:** Site statique sans build, une page HTML autonome par section (comme `fiches_kanji.html`). Les données sont un tableau JS `VERBS` dans la page ; les furigana sont écrits `漢字[よみ]` et transformés en `<ruby>` au rendu. Les dessins sont des JPEG pré-découpés dans `images/verbes/`.

**Tech Stack:** HTML/CSS/JS vanilla ; Python 3.12 + Pillow (venv du scratchpad, hors dépôt) pour la découpe ; node pour les vérifications.

**Spec:** `docs/superpowers/specs/2026-10-06-verbes-design.md`

## Global Constraints

- Style identique à `fiches_kanji.html` (variables `:root`, polices, cartes 3D, boutons `.controls`).
- Pas de filtres, pas de quiz, pas de romaji.
- Furigana sur chaque kanji des trois formes et du complément.
- Formes rédigées à partir des formes ます imprimées, pas des réponses manuscrites.
- `resource/` exclu de git ; le script de découpe reste hors du dépôt.
- Images : `images/verbes/01.jpg` … `30.jpg`, 400 px de large, niveaux de gris, fond blanc.
- Ne pas commiter sans demande explicite de l'utilisateur.

## Review Focus

- Kanji consécutifs avec une seule lecture (勉強[べんきょう], 写真[しゃしん]) : un seul `<ruby>` qui couvre tout le mot.
- Verbes sans kanji (かけます) ou complément en katakana (シャワーを) : affichés tels quels, sans `<ruby>` vide.
- Lecture qui change selon la forme (来[き]ます / 来[く]る / 来[き]て) : la bonne lecture sur chaque forme.
- Cartes étroites (≈150 px sur mobile) : les formes longues (勉強[べんきょう]します) ne débordent pas.
- Mélanger puis Tout retourner : toutes les cartes affichées se retournent, l'état du bouton est remis à zéro au mélange.

function ruby(s){
  return s.replace(/([一-鿿々]+)\[([^\]]+)\]/g,'<ruby>$1<rt>$2</rt></ruby>');
}
